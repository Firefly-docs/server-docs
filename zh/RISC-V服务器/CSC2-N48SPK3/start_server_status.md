# 服务器状态识别

服务器接入三角插头后，BMC 自动上电。

开始使用服务器前，请通过服务器上的电源按键/指示灯判断当前运行状态。

## 电源按键/指示灯

![电源按键/指示灯](../../../servers_img/CSC2-N48/front_view_led_power.png)

前面板有一个电源按键，用于控制所有子板的上电与下电。按键灯通过颜色和闪烁状态指示子板的电源状态：

- **熄灭**：服务器未上电。
- **黄色闪烁**：冷启动后的开机阶段，电源尚未就绪；电源就绪后转为绿色常亮，并默认开启所有子板。
- **绿色常亮**：子板处于开机状态。此时再次按下按键，按键转为黄绿交替闪烁，子板开始关机；关机完成后转为黄色常亮。
- **黄色常亮**：子板均处于关机状态。此时再次按下按键，按键转为绿色常亮，子板将陆续上电开机。
