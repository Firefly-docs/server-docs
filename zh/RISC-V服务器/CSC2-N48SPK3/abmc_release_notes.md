### v3.2.3（最新）

<details id="v323" open>
<summary>Web 会话自动续期；交换机串口终端容错</summary>

**新增**

- Web 会话自动续期：Access Token 有效期 2 小时，Refresh Token 12 小时；剩余不足 10 分钟时自动下发新令牌，持续操作无需重新登录

**修复**

- 三层交换机串口终端仅在串口无法访问时失败，其他异常状态仍可进入终端排查

**API**

- 新增令牌刷新接口 `POST /redfish/v1/token/refresh`；登录响应新增 `accessToken`、`refreshToken` 字段

</details>

### v3.2.2

<details id="v322">
<summary>芯片平台探测；挂载点重挂；端口速率自动协商</summary>

**新增**

- 子板芯片平台自动探测与手动指定（探测期间子板可能短暂重启）
- 文件共享挂载点支持重新挂载，无需删除重建
- 交换机端口与聚合口速率支持 `auto` 自动协商

**修复**

- BMC 启动后首次 UID 按键无响应、BM1684X 交换机串口终端无法打开
- GS1-N2 机型 NVIDIA 子板升级失败、BM1684X 网口命名规则错误

**API**

- 新增芯片类型查询/探测/指定、挂载点重挂接口

</details>

### v3.2.1（升级必读）

<details id="v321">
<summary>移除独立 SSH 用户体系；取消 ShareDisk 默认挂载</summary>

<Callout title="非兼容性变更" type="warn">
  本版本移除了独立 SSH 用户管理体系，并取消了 ShareDisk 默认挂载/NFS 导出，升级前请确认相关业务已调整。
</Callout>

**不兼容**

- 移除独立 SSH 用户管理体系，SSH 凭据统一由核心板通信配置提供；原 SSH 用户相关 API 全部移除
- 不再默认挂载 ShareDisk 到子板 `/media/NFS`，也不再默认 NFS 导出；存量挂载记录升级后首次恢复会失败一次，可手动删除

**优化**

- Web 终端统一入口：ADB / SSH / Shell 终端凭据自动取自当前通信配置，终端类型按实际状态实时计算

**修复**

- 子板强制下电后状态刷新不及时；CSC2 交换机端口拓扑映射错误

</details>

### v3.2.0（重点版本）

<details id="v320">
<summary>核心板通信方式管理；ADB 稳定性；QCOM8550 支持</summary>

**新增**

- 核心板通信方式管理：支持自定义 SSH、连通性测试、随时切回默认方式，SSH 链路支持断线自动重连
- 安卓核心板 ADB 稳定性提升（adbd 看门狗）；新增高通 QCOM8550 平台温度采集

**修复**

- 子板离线状态不刷新、SoC 型号识别误判、Bx 机型子板默认网关错误
- 5G 网卡 MAC 地址重启后不稳定、时间管理 NTP 默认值未沿用

**API**

- 新增核心板通信配置的查询、创建、测试、启用、删除接口

</details>

### v3.1.4（重点版本）

<details id="v314">
<summary>新版三层交换机管理；微服务自愈</summary>

**新增**

- 新版三层交换机管理：拓扑、端口、VLAN/SVI、聚合接口（Trunk）和 Web 控制台
- 微服务自愈：核心板微服务异常退出后可自动恢复

**修复**

- 4Kn 硬盘分区异常、存储信息刷新偶发崩溃、持久化挂载恢复失败
- Sophgo 平台内存信息采集、CS_B1 串口扩展芯片绑定

**API**

- 新增交换机拓扑、端口、VLAN、Trunk 和 Web 终端接口

</details>

### v3.1.3

<details id="v313">
<summary>C2、CSA1、NVIDIA Orin 多项修复</summary>

**修复**

- C2 机型开机时电源指示灯误亮红灯
- C2 前面板子板状态映射（在线、离线、升级中）
- CSA1 v1.1 硬件版本 SATA 硬盘指示灯兼容
- NVIDIA Orin 系列核心板存储容量改为按 NVMe 实际容量显示

</details>

### v3.1.2

<details id="v312">
<summary>IPv6 支持；移除 root 默认账户；时间管理修复</summary>

**新增**

- BMC 网络全面支持 IPv6：物理口、VLAN、Bond，支持双栈或纯 IPv6，含 DHCPv6/静态地址、网关、路由和 DNS

**变更**

- 移除 root 默认账户，仅保留 admin；admin 不再作为保留账户特殊保护

**修复**

- 默认时区错误、时区保存/恢复失效、时间服务重启后配置不生效
- C2 前面板屏幕刷新周期异常

**API**

- 网络配置和查询接口新增 IPv6 字段；通用响应不再输出 `Id`/`Name`

</details>
