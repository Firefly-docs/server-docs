# 服务器状态识别

服务器接入三角插头后，BMC 自动上电。

开始使用服务器前，请通过服务器上的指示灯判断当前运行状态。

![Front view](../../../servers_img/CSB1-N10/front_view.png)

## BMC 状态指示灯

![BMC 状态指示灯](../../../servers_img/CSB1-N10/front_view_led_bmc.png)

前面板上标有丝印 BS 的指示灯，是 BMC 的系统状态灯。指示灯为红绿双色灯，通过亮灭和颜色指示 BMC 的运行状态：

- **熄灭**：BMC 未上电。
- **绿色常亮**：BMC 正常进入系统。
- **红色常亮**：BMC 出现故障。

## 子板状态指示灯

![子板状态指示灯](../../../servers_img/CSB1-N10/front_view_led_subboard.png)

前面板上标有丝印 1～10 的 10 颗指示灯，分别对应 10 个子板的系统状态。指示灯为红绿双色灯，通过亮灭和颜色指示子板的运行状态：

- **熄灭**：子板未上电。
- **绿色常亮**：子板正常进入系统。
- **红色常亮**：子板出现故障。

## 交换机指示灯

![交换机指示灯](../../../servers_img/CSB1-N10/front_view_led_switch.png)

前面板上标有丝印 ES 的指示灯，是三层交换机的系统状态灯。指示灯为绿色单色灯，通过亮灭和闪烁频率指示三层交换机的运行状态：

- **熄灭**：交换机未上电或出现故障。
- **快闪（4 Hz）**：交换机正在启动。
- **慢闪（1 Hz）**：交换机正常工作。

## 万兆网口指示灯

![S1 指示灯与 SFP+1 光口的对应关系](../../../servers_img/CSB1-N10/front_view_led_sfp1.png)

![S2 指示灯与 SFP+2 光口的对应关系](../../../servers_img/CSB1-N10/front_view_led_sfp2.png)

前面板上标有丝印 S1、S2 的两颗指示灯是万兆光口状态指示灯，分别对应左侧的 SFP+1 和右侧的 SFP+2 万兆光口。指示灯为绿色单色灯，通过常亮和闪烁指示对应光口的运行状态：

- **常亮**：对应万兆光口已成功识别光模块。
- **闪烁**：对应万兆光口正在进行数据交换。


## UID 按键灯

![UID 按键灯](../../../servers_img/CSB1-N10/front_view_led_uid.png)

UID 按键灯是一盏黄色按键灯，按键与指示灯一体化设计，按下按键后，按键灯亮起。

服务器背面同样有一盏 UID 指示灯，与前面板按键灯联动：当前面板 UID 灯亮起时，背面的 UID 灯同步亮起。

![服务器背面的 UID 指示灯](../../../servers_img/CSB1-N10/rear_view_led_uid.png)

UID 灯用于帮助运维人员快速定位服务器。当机房中部署多台同款服务器时：

- **正面按下 UID 灯**：运维人员到背面接线或检查时，可根据点亮的 UID 灯定位服务器。
- **远程点亮 UID 灯**：远程运维人员发现服务器异常时，可在 aBMC Web 页面控制 UID 灯亮起，现场人员据此定位异常服务器。
- **现场按下 UID 灯**：aBMC Web 页面的 UID 虚拟 LED 会同步亮起，远程运维人员可确认待下架的服务器，方便下架前进行数据操作。


## 子板电源按键灯

![子板电源按键灯](../../../servers_img/CSB1-N10/front_view_led_power.png)

服务器正面面板有一个电源按键，用于控制所有子板的上电与下电。按键灯通过颜色和闪烁状态指示子板的电源状态：

- **熄灭**：服务器未上电。
- **黄色闪烁**：冷启动后的开机阶段，电源尚未就绪；电源就绪后转为绿色常亮，并默认开启所有子板。
- **绿色常亮**：子板处于开机状态。此时再次按下按键，按键转为黄绿交替闪烁，子板开始关机；关机完成后转为黄色常亮。
- **黄色常亮**：子板均处于关机状态。此时再次按下按键，按键转为绿色常亮，子板将陆续上电开机。
