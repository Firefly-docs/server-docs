
# Preface

## Overview
This document describes the appearance, structure, components, and specifications of the CSD2-N96XXX series server (hereinafter referred to as CSD2-N96), and guides users through the installation, cabling, power-on/power-off, basic configuration, operating system installation, and troubleshooting of the CSD2-N96.
## Intended Audience
This document is intended for:
- Enterprise administrators
- Enterprise end users

## Symbol Conventions

This document uses various warning symbols to distinguish risk levels. The meaning of each symbol is described in the following table:

| Symbol | Description |
| --- | --- |
| Danger | High-level risk that, if not avoided, will result in death or serious injury |
| Warning | Medium-level risk that, if not avoided, could result in death or serious injury |
| Caution | Low-level risk that, if not avoided, could result in minor or moderate personal injury |
| Notice | Safety notice related to equipment or environment. Failure to avoid it may cause equipment damage, data loss, performance degradation, or other unknown faults; no personal injury is involved |
| Note | Supplementary annotation for key content in the text. It is not a safety warning and carries no risk of injury to personnel, equipment, or environment |
